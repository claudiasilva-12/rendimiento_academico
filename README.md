# Proyecto de Rendimiento Académico

## Descripción

Este proyecto analiza el rendimiento académico de un grupo de estudiantes a partir de sus calificaciones en matemáticas, lectura y escritura.

El objetivo es encontrar patrones en las calificaciones y observar algunos factores relacionados con el rendimiento de los estudiantes.

## Dataset

El conjunto de datos contiene información de 1000 estudiantes y 8 variables.

Las principales variables utilizadas son:

- gender
- race/ethnicity
- parental level of education
- lunch
- test preparation course
- math score
- reading score
- writing score

## Análisis realizado

En el proyecto se realizaron los siguientes análisis:

- Promedio de calificaciones por materia.
- Comparación de calificaciones según el curso de preparación.
- Comparación según el nivel educativo de los padres.
- Correlación entre las calificaciones.
- Cálculo del promedio general de cada estudiante.
- Clasificación de los estudiantes en niveles de rendimiento.

## Visualizaciones

El proyecto genera seis gráficas:

1. Promedio de calificaciones por materia.
2. Promedio según curso de preparación.
3. Promedio según educación de los padres.
4. Correlación entre las calificaciones.
5. Distribución del promedio general.
6. Cantidad de estudiantes por nivel de rendimiento.
